Meeting-to-CRM Assistant

PYTHON • STARLETTE • SQLITE • GEMINI API

Built a transcript-to-CRM review workflow with a Starlette web interface and SQLite. Each transcript is linked to an exact deal ID and the system drafts evidence-backed follow-ups in offline or Gemini mode.

Human approval is enforced before CRM writes using quote and turn checks, duplicate detection, deal-version conflict protection and transactional updates. The system also includes completion history, deletion safeguards, audit events and a token-protected API.

02

Secure RAG with Role-Based Access Control

RAG • RBAC • VECTOR RETRIEVAL • SECURITY

Designed a retrieval-layer RBAC pipeline that authenticates users, loads current permissions, filters vector retrieval before ranking and context construction, and returns only authorized answers and citations.

The design addresses dynamic permission revocation, stale-cache prevention, end-to-end leakage evaluation and security-performance overhead. Evaluation metrics include Precision@k, Recall@k, unauthorized exposure rate, response time, RBAC overhead, revocation delay and citation authorization.
